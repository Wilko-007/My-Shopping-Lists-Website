# My Shopping Lists — Promotional website

Static, responsive marketing website for https://myshoppinglistsapp.com.

## Deploy

Serve the repository root as the website directory. Porkbun Static Hosting GitHub Connect should point to this repository's `main` branch once ready to publish. `index.html` must remain at the root.

## Assets

Images are supplied by the app owner. `assets/hero-banner.webp` is retained as an Open Graph social-sharing image. No analytics or tracking code has been included.

## Before publishing

- Review all copy, screenshots, pricing descriptions, and download link.
- Confirm legal/privacy-policy URLs and add approved policy pages/links (not invented in this version).
- Check the support mailbox works and app data-disclosure language is consistent with the privacy policy.
- If needed, add Google Analytics only after consent/privacy requirements are addressed.
- Test on mobile and desktop.
